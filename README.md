# Бюро переселения привидений

- Приложение: https://tais0ft.github.io/ghost-bureau/
- Репозиторий: https://github.com/Tais0ft/ghost-bureau

Веб-приложение для оператора ночной смены: заявки привидений, места обитания, автоподбор с объяснением, ручная правка, отчёт и AI Worklog внутри интерфейса.

Живое демо собирается статикой и открывается без бэкенда и без секретов.

## Запуск

Нужны Node.js 22+ и npm.

```bash
npm install
npm test
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://localhost:5173).

Сборка для проверки продакшен-версии:

```bash
npm run build
npm run preview
```

## Как проверить за минуту

1. На экране **Очередь** уже загружена «Ночная смена». У каждой заявки есть место или причина отказа.
2. Селектор **Сценарий проверки** переключает обязательные состояния:
   - **Ночная смена** — обычная работа, есть просрочка и нехватка чердака.
   - **Пустая очередь** — нет заявок.
   - **Невозможное** — заявка без подходящего места (чердак замка опечатан).
   - **Переполнение** — четыре чердачных привидения на три места в замке.
   - **Повреждённый журнал** — ошибка загрузки с понятным текстом.
3. В карточке заявки смените место вручную на заведомо плохое (например, солярий для тревожного привидения). Появится предупреждение, что именно не так.
4. Вкладки **Места** и **Отчёт** показывают занятость, перегруз и проблемные заявки.
5. **Журнал AI** — экран worklog, не только README.

## Формула подбора

Жёсткий отказ, если сработало любое условие:

- дедлайн уже прошёл;
- нет свободных мест;
- особое условие конфликтует с местом (чердак, зеркала, люди, сырость, свет, шум, холод).

Иначе балл из 100:

| Часть | Максимум |
| --- | --- |
| Температура | 25 |
| Свет под тревожность | 20 |
| Шум под тревожность | 15 |
| Влажность | 10 |
| Свободная вместимость | 15 |
| Близость дедлайна | 15 |

Автоподбор идёт по дедлайну, затем по тревожности. Ручной выбор можно сохранить даже если он плохой — бюро предупредит, а отчёт покажет перегруз.
